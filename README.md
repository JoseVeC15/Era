# Era Nails & Hair - Experiencia Visual Revolucionaria 🚀

Página web avant-garde con tecnologías 3D, generación procedural y micro-interacciones extremas. Diseñada para revolucionar la experiencia visual en la industria de estética.

## 🎨 Tecnologías Implementadas

### 3D & Gráficos
- **Three.js** - Escena 3D interactiva con partículas dinámicas
- **Canvas API** - Fondo generativo procedural con conexiones de red
- **WebGL Shaders** - Renderización acelerada por GPU
- **SVG Morphing** - Transiciones suaves entre formas orgánicas

### Animaciones & Interacción
- **GSAP 3** - Timeline profesionales y ScrollTrigger
- **Lenis** - Smooth scroll extremadamente fluido
- **Intersection Observer** - Animaciones basadas en scroll
- **Micro-interacciones** - Botones magnéticos, cursores personalizados

### Stack Base
- **HTML5 Semántico**
- **CSS3** - Glassmorphism, gradients animados, backdrop filters
- **JavaScript Vanilla** - Sin dependencias externas (excepto librerías de animación)
